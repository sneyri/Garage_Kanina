# Гараж Канина

Рутинный хоррор про зимний гаражный кооператив. Каждый вечер приходишь к Канину и делаешь, что он скажет: моешь пол, разбираешь канистры, чинишь питбайк. А в полу гаража есть запертый люк в подвал.

Это прототип. В нём есть локация, механики дней и заданий, меню, звук и несколько пробных пугалок.

## Запуск

Дважды кликните `index.html`. Игра откроется в браузере. Сервер, сборка и интернет не нужны.

Проверено в Chrome и Edge (Windows). Код рассчитан и на Firefox, и на Safari: нет ES-модулей, везде есть запасные варианты API. Но в них игру ещё никто не запускал.

Нужны клавиатура и мышь.

| Клавиша | Действие |
|---|---|
| `W A S D` | идти (работает и на русской раскладке) |
| `Shift` | бежать |
| мышь | смотреть (клик по игре захватывает курсор) |
| `E` | взять, поставить, поговорить; некоторые дела нужно удерживать |
| `F` | налобный фонарь |
| `G` | бросить предмет |
| `Y` / `N` | ответить на звонок / сбросить |
| `Esc` | пауза |
| `F2` или `Ё` | отладочная панель |

## Что уже есть

- **Локация.** Два ряда гаражей, проезд со снегом и колеёй, проулок с мусорным баком, фонари (один мигает, один не горит), бетонные заборы, берёзы, девятиэтажки на горизонте, снегопад.
- **Гараж Канина.** Смотровая яма под досками, жёлтый питбайк «75», стеллаж, верстак, тумба с LED-панелью и свечой, лампочка на провисшем проводе, щиток, мешки цемента, шины, куртка на гвозде, люк в подвал.
- **Дни.** День 1 — уборка: пятна масла, канистры, масло, мусор. День 2 — питбайк: бензин, трос сцепления, камера, насос. После второго дня экран «Конец прототипа». Результаты прошлых дней остаются на месте.
- **Канин.** Ждёт у верстака, даёт задания, потом бродит по гаражу и проезду, бормочет и светит красным налобником.
- **Пугалки.** Режиссёр сам выбирает событие раз в 35–70 секунд:
  - лязг и скрип вдалеке, стук из подвала, мигание лампы;
  - «Тип» вдалеке, в воротах или за спиной;
  - звонок от «Смерть В Нищете»;
  - выбитые пробки: свет гаснет, нужно поднять рубильник на щитке.
- **Звук.** Музыка меню, ветер, гул лампы, шаги по снегу, бетону и доскам. Всё синтезируется через Web Audio, аудиофайлов нет.
- **Сохранения.** В начале и в конце каждого дня.

## Архитектура в стиле NestJS

В Nest код делится на модули, сервисы и контроллеры, а связывает их DI-контейнер. Здесь то же самое, только на чистом JS и без сборщика. Декораторы применяются вручную, так же, как это делает компилятор TypeScript.

```js
// В NestJS (TypeScript):
@Injectable()
@Dependencies(StorageService, EventBus)
export class SettingsService { constructor(storage, events) {} }

// Здесь (src/modules/settings/settings.service.js):
GK.SettingsService = decorate([Injectable(), Dependencies(GK.StorageService, GK.EventBus)], SettingsService);
```

| NestJS | Здесь |
|---|---|
| `@Module`, `@Injectable`, `@Global`, `@Controller` | `GK.common` — `src/core/decorators.js` |
| `@Get('path')` | `Action('new-game')` + кнопка `data-action="menu/new-game"` |
| `NestFactory.create(AppModule)` | `src/main.js` |
| DI-контейнер, области видимости, `exports` | `src/core/container.js` |
| `onModuleInit`, `onApplicationBootstrap`, `onModuleDestroy` | те же хуки |
| `{ provide, useValue / useFactory / useClass / useExisting }` | поддерживаются |
| `Test.createTestingModule().overrideProvider()` | `src/core/testing.js` |
| `@nestjs/event-emitter` | `EventBus` в `SharedModule` |
| `Logger` | `GK.common.Logger` — пишет в консоль браузера, как Nest |

Дерево модулей (`src/app.module.js`):

```
AppModule
├─ SharedModule (глобальный) ─ EventBus
├─ StorageModule ─ localStorage, cookie, память, сохранения
├─ SettingsModule ─ настройки
├─ GameStateModule ─ boot / menu / cutscene / playing / paused / ending
├─ InputModule ─ клавиатура, мышь, захват курсора
├─ AudioModule ─ звуковой движок, эффекты, музыка
├─ EngineModule ─ рендерер three.js, игровой цикл
├─ WorldModule ─ текстуры, материалы, предметы, гаражи, снег, столкновения
├─ PlayerModule ─ игрок, фонарь, руки, взаимодействие
├─ NpcModule ─ персонажи, реплики, Канин
├─ DaysModule ─ конфиг дней, задания, предметы, распорядок дня
├─ HorrorModule ─ «Тип», звонок, режиссёр пугалок
└─ UiModule ─ контроллеры: меню, настройки, пауза, карточки, HUD, отладка
```

Модули общаются через `EventBus` (`state.changed`, `task.completed`, `horror.scare` и т.д.), поэтому циклических зависимостей нет. Если всё же ошибиться, контейнер объяснит это по-русски в духе Nest: «Не могу разрешить зависимости X (?)…», «Циклическая зависимость: A → B → A».

Важно: скрипты подключены обычными `<script>` в `index.html`, и порядок имеет значение. Класс должен быть объявлен раньше, чем его упомянут в `Dependencies()`. ES-модули не используются, потому что браузеры не грузят их с `file://`.

В консоли браузера есть `app`: `app.get(GK.DaysService)`, `app.dispatch('debug/skip-day')`.

## Как добавить день

Откройте `src/modules/days/days.config.js` и добавьте объект в `GK.DAYS`: реплики Канина, предметы с координатами и задания (`talk`, `clean`, `deliver`, `use`, `leave`). Код менять не нужно. Потом запустите тесты: они проверят, что цели существуют, предметов хватает и ничего не застряло в стенах.

## Тесты

- **В браузере:** дважды кликните `test/index.html`. Пройдут все тесты, включая проверки 3D-мира.
- **В терминале:** `npm test`. Нужен только Node, зависимостей нет. Тесты мира здесь пропускаются.

Мини-фреймворк в духе Jest лежит в `test/lib/gk-test.js`, подделки localStorage и cookie — в `test/lib/fakes.js`.

## Сохранения

Прогресс и настройки хранятся в `localStorage`. Номер дня и настройки дублируются в cookie. Если `localStorage` недоступен, игра перейдёт на cookie, а если нет и их — будет хранить всё в памяти до перезагрузки.

Chrome и Edge не сохраняют cookie у страниц, открытых как файл (`file://`). Там работает только `localStorage`, и это нормально. Cookie заработают, если игру выложить на сайт.

## Отладка

- `F2` или `Ё` — панель: вызвать любую пугалку, пропустить день, телепорт к гаражу, стереть сохранение.
- `index.html?scene=garage` — сразу в игру у гаража Канина. Есть ещё `menu`, `lane`, `inside`, `day2`.
- `index.html?nolock` — без захвата курсора: смотреть, зажав левую кнопку мыши.
- `index.html?debug` — панель открыта сразу.

## Фото звонящего

Чтобы на экране звонка было фото, как на скриншоте, положите картинку в `assets/img/caller.jpg`. Без неё там тёмный силуэт.
